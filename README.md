# ARSLAN ELEKTRİK

Premium website for **ARSLAN ELEKTRİK** — Samsun / Türkiye.

## Stack

- Next.js 15 · React 19 · TypeScript
- Tailwind CSS 4 · Framer Motion · GSAP · Lenis
- Embla Carousel · React Hook Form · Zod · Lucide

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3002](http://localhost:3002).

## Build

```bash
npm run build
npm start
```

## Pages

| Route | Page |
|-------|------|
| `/` | Ana Sayfa |
| `/hizmetler` | Hizmetler |
| `/projeler` | Projeler |
| `/iletisim` | İletişim |

Update phone, WhatsApp and address in `src/lib/siteConfig.ts` before go-live.
